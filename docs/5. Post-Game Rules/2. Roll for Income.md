# Roll for Income
## Income

At the end of the game, roll for income. To do so, do the following:

1. Check the number of Treasure token you obtained during the game
	1. Add an additional Treasure if you won the game
2. Roll a d20 for each Treasure token and add the values together
	1. Add 40g to the total value, which becomes your total gold earned
	2. For every 20 rolled on the d20, you may earn an Artifact, described in the section below.
		1. If no Artifacts remain, instead roll an additional d20 and add that to the total value. If another 20 is rolled, repeat the process.
3. Update your warband sheet by adding your earned gold to any existing gold.

Some Treasure tokens may be worth double. In this case, roll an extra d20 for it during Step 2 above.
## Artifacts

When you roll a 20 during the Income rolls, you can earn an Artifact! Roll another d20 and consult the following table to determine which Artifact has been earned.

| d20   | Name | Description |
| ----- | ---- | ----------- |
| 1     |      |             |
| 2-7   |      |             |
| 8     |      |             |
| 9     |      |             |
| 10    |      |             |
| 11    |      |             |
| 12-14 |      |             |
| 15-16 |      |             |
| 17    |      |             |
| 18    |      |             |
| 19    |      |             |
| 20    |      |             |
|       |      |             |

There is a cap on the amount of Artifacts available through Income rolls for each campaign. Those created by Neutral Heroes do not count towards this cap. The cap is dependent on the number of players, as shown in the table below.

| Total Players | Artifact Cap |
| ------------- | ------------ |
| 2             | 1            |
| 3             | 1            |
| 4             | 1            |
| 5             | 2            |
| 6             | 2            |
| 7             | 3            |
| 8             | 3            |
Once all Artifacts are found via rolling Income, if a 20 is rolled during the Income step, instead roll an additional d20 and add that to the total income.
