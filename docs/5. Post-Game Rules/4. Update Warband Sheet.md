# Update Warband Sheet

After the game is over, some things need to be tracked on the warband sheet:
* Any units that are Blighted should be marked as such, if you have not done so already
* Wins and Losses should be updated
* Update Neutral Heroes
	* Remove Neutral Heroes that you lost Alignment with
	* Add Neutral Heroes that you gained Alignment with
	* Update Neutral Heroes that you gained Patronage with
		* Inform the rest of the players in the campaign, so they know that no one can align with that Neutral Hero and that you can no longer align with another Neutral Hero

When a Neutral Hero becomes your Patron, you gain the following benefits:
* You may hire your Patron at half the cost as normal via Rally Support
* You always have first choice to hire them via Rally Support before others
* No one can hire your Patron to fight against you via Rally Support
