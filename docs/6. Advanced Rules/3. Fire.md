## Burning Buildings

Under certain circumstances, buildings can catch on fire. If a building is Burning, it will continue to do so until the end of the battle. Burning buildings can still be entered and moved around in as normal. If a unit ever ends their turn in a building that is Burning, they must make a Mishap Roll.

At the start of each turn of the player (or neutral unit) whose turn it was when the building started Burning, it will spread once. If a walkway is connected to a building that is Burning, it is also starts Burning. Similarly, if a building is connected by a walkway that is Burning, it also starts Burning.

For example: Alice causes a building to start Burning on her turn. Bob then takes his turn. When it reaches Alice's turn again, the fire spreads. There are two walkways connected to the building, which both start Burning. At the start of Alice's next turn, the fires on these walkways spread. The buildings that they were connected to now start Burning. This continues until the fire cannot spread any further.
