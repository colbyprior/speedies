# Quick Reference

This page can be used as a reference for common rules which use tables or specific values that may not be easy to recall.


## Pre-Game

### Pre-Game Steps

1. Rally Support
2. Set up map
3. Deploy warbands
4. First player begins their turn

### Rally Support

25g for each win less than your opponent. No Support if tied.
### Treasure Tokens Per Game

| Game | Tokens |
| ---- | ------ |
| 1    | 7      |
| 2    | 6      |
| 3+   | 5      |


## Game Rules

### Turn Phases

Turns are broken up into six phases:
1. [Upkeep](docs/4.%20Game%20Rules/2.%20Upkeep%20Phase.md)
2. [Engage](docs/4.%20Game%20Rules/3.%20Engage%20Phase.md)
3. [Move](docs/4.%20Game%20Rules/4.%20Move%20Phase.md)
4. [Cast](docs/4.%20Game%20Rules/5.%20Cast%20Phase.md)
5. [Ranged](docs/4.%20Game%20Rules/6.%20Ranged%20Phase.md)
6. [Melee](docs/4.%20Game%20Rules/7.%20Melee%20Phase.md)

### Upkeep Phase Steps

The upkeep phase is divided into five steps, which are done in order. The steps are:
1. Neutrals
2. Rout
3. Recover
4. Treasure
5. Ongoing Spells

#### Routing
Player's Units Lost + Opponent's Treasures Held >= (6 or 7 depending on warband)

### General
#### Injuries for Melee/Ranged Attacks

| Attack d20 Roll | Result                                         |
|-----------------|------------------------------------------------|
| 1-14            | Dazed                                          |
| 15-17           | Stunned                                        |
| 18-20           | Incapacitated                                  |

#### Mishap Rolls

| d20 Roll | Result        |
| -------- | ------------- |
| 1-11     | No effect     |
| 12-14    | Dazed         |
| 15-17    | Stunned       |
| 18-20    | Incapacitated |

#### Blight Effects

The Blight has the following effects during battle:

1. Units with the Blight gain Advantage on Melee Checks during the first turn of any new combat.
2. If a unit Incapacitates or is Incapacitated by a unit with the Blight in Melee, they must make a Morale Check. If it fails, they immediately contract the Blight.
	1. If the unit that was Incapacitated already has the Blight then nothing happens.


### Engaging

#### Out-of-Sight Rolls

| d20   | Engage Distance           |
| ----- |---------------------------|
| 1-10  | The unit is Slowed.       |
| 11-20 | Engage Distance is normal |

If the Engage fails, the unit moves toward the target as far as its current Move allows (3" less if Slowed).

#### Jump Attack
A unit may perform a Jump Attack under all of the following conditions:
- As part of your Engage you make a successful Jump Down check
- Where you land after your Jump Down check directly engaged with a unit

If you successfully perform a Jump Attack you roll your attacks with Advantage for the current turn.

#### Fear

| Morale Check Result | Effect                                     |
| ------------------- | ------------------------------------------ |
| Passed Morale check | Nothing happens                            |
| Failed Morale check | Unit is Weakened for the rest of the turn  |


### Moving

#### Jumping
Make an agility check to jump across a gap of up to 3” and a height of up to 1”. If you fail then you fall.

#### Dropping down

Place the unit on the ground within 3" (or its Jump Across distance, if greater) and make an Agility Check to see if it safely landed. On a success, it lands and may continue Moving as normal. If it fails it Falls, stopping where it landed. Resolve Falling as normal.

#### Falling damage
Make a Mishap Roll. For every extra full inch above 2” that the unit falls from, add +2 to the Mishap Roll. Units that fall do not actually lose a Wound (which is only relevant for multi-wound units). If they would be Incapacitated when they have more than 1 Wound remaining, they are instead Stunned and lose a Wound.

#### Difficult Terrain

-2" to Move, once per turn regardless of how much Difficult Terrain is crossed. Stacks with Slowed. Walls and Fences up to 1" high count as Difficult Terrain.

### Casting

#### Casting Restrictions
A unit may Cast while Engaged, but not while Stunned or Dazed. A unit that attempts to Cast cannot Shoot in the same turn, whether or not the Cast succeeds.

#### Ongoing Spells

If the Caster is Stunned or Incapacitated, the Ongoing Spell immediately ends.



### Ranged

#### Being Elevated

If an enemy is at least 2" below your Shooting unit and within half range of the Ranged Weapon being used (this can only be measured after declaring the target to be Shot at), then the unit Shooting has Advantage on their Ranged Check.

#### Shooting modifiers

| Modifier        | Effect    |
| --------------- | --------- |
| Cover           | -3 Pierce |
| Moved this turn | -3 Pierce |



### Melee

#### Attacking a unit that is Dazed or Stunned

| Status  | How To Incapacitate                                                              |
| ------- | -------------------------------------------------------------------------------- |
| Dazed   | No Melee Check. The target makes a Defence Check per attack; any failure Incapacitates |
| Stunned | Incapacitated automatically (but costs one attack to do so)                      |



## Post-Game
### Post-Game Steps

1. Gather Treasure
2. Roll for Income
3. Update Warband Sheet
4. Resolve Promotions
5. Roll for Scars & the Blight
6. Free Improvement Attempts
7. Neutral Hero Progression
8. Learn Skills & Spells
9. Spend Gold

### Income

40g + d20g for each Treasure token (+1 Treasure token for winning). Double-value Treasure tokens roll an extra d20. Each 20 rolled may earn an Artifact; if none remain, roll another d20 instead (repeating on further 20s).


### Hero Scars

| d20   | Name            | Result                                                                                                           |
| ----- | --------------- |------------------------------------------------------------------------------------------------------------------|
| 1     | Blight          | This unit contracts the Blight or gains 'Deathtouched' if they already have the Blight.                          |
| 2-7   | Deathtouched    | Check the 'Deathtouched' checkbox. If this is already checked, the unit dies.                                    |
| 8     | Madness         | This unit gains the Madness special rule                                                                         |
| 9     | Leg Wound       | This unit gains 'Slow' special rule                                                                              |
| 10    | Major Wound     | Roll again: 1-5 Worsen Defence by 2, 6-10 Worsen Melee by 2, 11-15 Worsen Ranged by 2, 16-20 Worsen Agility by 2 |
| 11    | Light Wound     | Miss the next game                                                                                               |
| 12-14 | Nothing happens | Nothing happens                                                                                                  |
| 15-16 | Pit Fight!      | Pit Fight (see below)                                                                                            |
| 17    | Berserk         | This unit gains the Berserker special rule                                                                       |
| 18    | Disfigured      | This unit gains the Fear special rule                                                                            |
| 19    | Hatred          | This unit gains Hatred for the opposing warband                                                                  |
| 20    | Improvement     | This unit immediately draws two Improvement Cards and chooses one to resolve.                                    |


### Henchmen Scars

| d20  | Result                                                                  |
| ---- | ----------------------------------------------------------------------- |
| 1    | This unit contracts the Blight or dies if they already have the Blight. |
| 2-4  | Death                                                                   |
| 5-20 | Nothing happens                                                         |


### Blight Roll

After rolling for Scars, units that have the Blight must roll to see how the Blight progresses.

| d20   | Result                                |
| ----- | ------------------------------------- |
| 1-4   | Henchman: Death, Heroes: Deathtouched |
| 5-15  | Nothing happens                       |
| 16-20 | Recover from the Blight               |

### Buying Hero Slots

Players can spend gold to increase their total Hero Slots and enable them to hire Heroes beyond the usual 3. This can be especially useful if the player has gotten unlucky with Henchman Promotion rolls and is feeling limited by their Hero Slots. See the following table for the cost required to buy a Hero slot. The costs listed are not cumulative.

| Hero Slot | Cost |
| --------- | ---- |
| 4th       | 60g  |
| 5th       | 100g |
| 6th       | 140g |

Each slot costs 5g less for every game played (eg. after 3 games, the 5th slot costs 85g).

### Buying Improvement Attempts

Players can spend 25g to allow a Hero to make an Improvement Attempt. Draw once from the Improvement Deck for that Hero and resolve the card. Each Hero can only attempt to Improve once between each game.
